# Design

## Overview

This portfolio uses a professional, modern dark interface designed for a Data Engineer, Data Analyst, and AI Engineer.

## Visual Direction

- Dark deep-navy background
- Blue/cyan accent color
- Clean typography
- Minimal borders and subtle card surfaces
- Technical and professional visual language
- Responsive layout for desktop, tablet, and mobile
- Single-page navigation with smooth scrolling

## Color Palette

| Purpose | Color |
|---|---|
| Background | `#071019` |
| Card Background | `#0D1B27` |
| Primary Accent | `#38BDF8` |
| Main Text | `#F4F7FB` |
| Secondary Text | Blue-gray / muted white |
| Borders | Subtle slate/white transparency |

## Typography

The primary typeface is **Inter**, with system sans-serif fallbacks.

Technical labels may use a monospace font to reinforce the engineering aesthetic.

## Layout

The page is organized into:

1. Hero
2. About
3. Engineering Approach
4. Experience
5. Projects
6. Skills
7. Contact
8. Footer

All sections are part of the same page and are accessible through the navigation bar.

## UI Principles

- Keep the interface clean and readable.
- Use whitespace to separate major sections.
- Use blue accents sparingly for emphasis.
- Keep cards subtle rather than heavily decorated.
- Maintain strong contrast between text and the background.
- Use motion only where it improves interaction.
- Avoid unnecessary visual elements that distract from the portfolio content.

## Responsive Design

The layout should adapt to:

- Desktop screens
- Tablets
- Mobile phones

Horizontal overflow should be prevented, and interactive elements should remain easy to use on smaller screens.
