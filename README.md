# Mohamed Hisham Gad — Portfolio

Personal portfolio website for **Mohamed Hisham Gad**, a Data Engineer, Data Analyst, and AI Engineer.

The portfolio is designed as a modern, responsive, single-page website that presents Mohamed's professional background, education, experience, projects, technical skills, and contact information.

---

## Overview

This portfolio was built to provide a professional online presence and showcase experience across:

- Data Engineering
- Data Analytics
- Artificial Intelligence
- Machine Learning
- Software Engineering
- Data Visualization

The website follows a clean, professional dark design with blue/cyan accents and a technical visual style.
